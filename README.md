# 🏢 Mini ERP — Project Management System

A full-stack Mini ERP system for managing projects, tasks, and team workflows. Built as a screening project for a Full Stack Developer role.

🔗 **Live Demo:** [erp-system-eight-plum.vercel.app](https://erp-system-eight-plum.vercel.app)

---

## Features

- 📋 Project creation and management
- ✅ Task tracking with status updates
- 👥 Team role assignment
- 📊 Project progress overview
- 🔐 User authentication

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React.js |
| Backend | Node.js, Express.js |
| Database | MongoDB |
| Deployment | Vercel |

---

## Getting Started

```bash
# Clone the repo
git clone https://github.com/jesse-aj/ERP_SYSTEM.git

cd ERP_SYSTEM/mini-erp

# Install dependencies
npm install

# Run the app
npm start
```
